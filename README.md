# G1-IoT-HW2-Multiple-Linear-Regression

本專案使用 Kaggle 的 Student Performance Factors 資料集，建立多元線性回歸模型來預測 Exam_Score，並依 CRISP-DM 流程完成從資料理解、前處理、建模到評估與可視化（含預測區間）。

資料集來源：https://www.kaggle.com/datasets/lainguyn123/student-performance-factors

專案結構
```
├─ 7114056073_HW2.py           # 主程式
├─ data/
│  └─ student_performance.csv  # 原始資料集
├─ Reports/
│  ├─ GPT_consersation/        # GPT對話流程
│  ├─ Report.pdf               # 作業報告（含 NotebookLM 摘要）
│  └─ Report.md                # 報告原始檔
├─ result.png                  # 執行結果
└─ README.md                   # 本文件
```
